
# Ur/Web Safe Message Board

## Overview

This project demonstrates the development of a secure web application using Ur/Web. The application is a simple message board where users can submit messages that are stored and displayed.

## Objectives

* Model functional requirements of a web application
* Implement the application using Ur/Web
* Demonstrate built-in security features of Ur/Web
* Explore automated translation into Ur/Web

## Features

* Submit a message with a username
* Store messages in a database
* Display all submitted messages

## Security

Ur/Web ensures:

* Protection against SQL injection
* Prevention of Cross-Site Scripting (XSS)
* Type-safe database interactions
